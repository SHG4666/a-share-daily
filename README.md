# A股每日量化复盘 → 飞书

每个交易日北京时间 17:13 由 Claude 定时任务触发并检查是否发送成功，失败会重跑或修复（GitHub 自带定时延迟严重，只保留 21:37 兜底；当天只推一次），向飞书群推送复盘卡片。股票名可点击跳转雪球。

目标：选出**连续上涨或可能连续上涨**的股票，每天复盘上一交易日的表现，自动调整策略。

## 卡片结构

1. **市场概况**：涨跌家数、成交额、沪深300 状态、领涨行业
2. **📝 昨日复盘**：上一交易日推荐的股票今天的表现，按策略拆分
3. **🔧 今日策略调整**：各策略今天分到几个名额、为什么
4. **🎯 今日推荐**：最终推荐，标注来自哪个策略
5. **📌 推荐跟踪池**：最近 10 个交易日推荐过的股票，显示累计涨幅、连涨天数，以及是否跌破止损
6. **📈 策略战绩**：每个策略的次日胜率、3 日超额收益、5 日内平均上涨天数

## 策略库

| 策略 | 思路 | 核心条件 |
|---|---|---|
| 🔥 强势延续 | 押注已有上涨继续 | 均线多头；20 日涨 8–45% 且对数回归 R² ≥ 0.6；接近 60 日新高；偏离 20 日线 ≤ 15%；温和放量 |
| ↩️ 趋势回踩 | 上升趋势中的回调买点 | 20 日线 > 60 日线且 60 日线上行；从 20 日高点回撤 4–15%；触及 20 日线；缩量；今日收涨 |
| 🚀 底部启动 | 长期下跌后的反转 | 一年内跌 ≥ 30%；低位；反弹 5–25%；站上 20 日线；放量 |
| 🛡️ 稳健多因子 | 好公司 + 稳趋势 | 行业中性化 EP/BP/ROE/低换手 → 60 日趋势、波动、回撤 |

每个策略对满足条件的股票打分（因子先经 MAD 去极值和标准化，再加权），然后在行业内分散，取前 12 只作为候选。

## 自我复盘与名额分配（`alloc.py`）

1. 每只推荐都会记录次日、3 日、5 日收益和同期沪深300 收益（`data/picks.csv`）
2. 奖励 = 推荐后每天的平均超额收益（有 3 日数据就用 3 日的，否则用次日的）
3. 按时间衰减加权（半衰期 7 个交易日），越近的表现越重要
4. 每个策略的期望收益用正态后验表示：数据少时向 0 收缩、不确定性大
5. 蒙特卡洛模拟每个策略"是最好策略"的概率，按这个概率分配每天的 10 个名额
6. 效果：表现好的策略多给名额；没数据或很久没用的策略会自动获得探索机会；所有策略都跑输时减少推荐数

其他规则：最近 3 个交易日推荐过的股票不再重复推荐（在跟踪池里继续看）；同一行业最多 3 只。

参数都在 `config.py`。

## 部署

Secrets：`FEISHU_WEBHOOK`（必填）、`FEISHU_SECRET`、`ANTHROPIC_API_KEY`（选填）。
手动运行：Actions → A股每日推荐 → Run workflow（可选强制运行 / 只打印不推送 / 行情源）。

## 局限

- 数据来自免费接口（东方财富 / 腾讯 / 新浪），海外服务器常被东方财富限流，会自动切换备用源
- 推荐和回测都按收盘价计算，实际买入一般在次日开盘
- 策略权重和阈值是先验设定，名额分配需要积累几周数据才会稳定
- 仅供研究参考，不构成投资建议

## 夜间回测（`backtest.py`，每个交易日 22:07）

用真实历史行情回放过去 120 个交易日。每一天只用当时能看到的数据，让每个策略按原规则选前 10 只，再记录之后 1/3/5 天的真实收益。
同时设两个对照组：🎲 随机基准（每天随机选 5 只）、📈 追涨基准（每天买涨幅 5~9% 的成交额前 5 只）。

报告推送到飞书：每个策略的日均超额收益及 t 值（|t|≥2 大致说明不是运气）、次日胜率、3 日超额、5 日内平均上涨天数、连涨率。
结果保存在 `data/backtest.csv`，第二天名额分配时作为先验起点，打五折，相当于 4 个实盘样本，再叠加实盘推荐的真实表现。

股票池为全市场：剔除 ST、北交所、当前市值 < 50 亿，回放的每一天再按当天成交额 ≥ 1 亿过滤，和实盘规则一致。
近似：按当前上市状态和市值筛选，有幸存者偏差；回放中没有历史换手率；稳健多因子用的是当前 PE/PB，有前视偏差。

## 全市场历史行情缓存（`histstore.py`）

每日选股和夜间回测都扫描全市场，不设候选数量上限。逐只拉取全市场历史数据约需 5000 次请求，所以做了缓存：

- 首次全量拉取约 400 个交易日的前复权日线，存到 `cache/hist.pkl.gz`，通过 GitHub Actions cache 跨次运行保留，不进 git
- 之后每天用全市场快照（约 20 次请求）给每只股票追加当天 K 线
- 快照的"昨收"和缓存最后一天的收盘价对不上时（除权除息、中间缺数据），这只股票会自动重新完整拉取
- 拉取有时间预算，没拉完的下次继续补；手动运行"策略夜间回测"并选 mode=build，可以只构建缓存
- 成交量统一用"手"
