# A股每日量化复盘 → 飞书

每个交易日收盘后（北京时间 16:07）自动运行，向飞书群推送复盘卡片。股票名可点击，跳转雪球查看走势。

## 选股模型：先选好公司，再选好时机

**股票池**：剔除 ST、北交所、涨跌停、市值 < 50 亿、成交额 < 1 亿、上市不足约 200 个交易日的股票。

**第一阶段：全市场截面多因子**

| 因子 | 计算 | 依据 |
|---|---|---|
| EP | 1 / PE | 价值因子，盈利收益率 |
| BP | 1 / PB | 价值因子 |
| ROE | PB / PE | 质量因子（ROE = E/B = (P/B)/(P/E)） |
| 低换手 | −ln(换手率) | A 股显著的低换手溢价 |

每个因子先做 MAD 去极值（中位数 ± 5 倍 MAD），再在**行业内部**标准化（行业中性化，避免银行等低估值行业霸榜），然后加权合成，取前 150 只。

**第二阶段：时间序列统计**

| 指标 | 计算 |
|---|---|
| 趋势强度 | 对 ln(收盘价) 做 60 日线性回归，年化斜率 × R²（涨得多且涨得稳） |
| 低波动 | 60 日日收益率标准差 × √250 |
| 回撤 | 60 日最大回撤 |
| 短期反转 | 近 5 日涨幅，越低越好（A 股短期反转效应） |

硬条件：趋势向上、R² ≥ 0.4、站上 60 日均线。五项标准化后加权得到综合分，取前 5 只。

**市场状态**：沪深300 跌破 60 日线视为弱势，推荐数降为 3 只。

**风控**：参考止损 = 收盘价 − 2 × ATR(14)。

**策略追踪**：每天的推荐会记录到 `data/picks.csv`。第 5 个交易日用真实价格回测，在卡片中展示胜率、平均收益和相对沪深300 的超额收益，用数据检验模型是否有效。

所有权重和阈值都在 `config.py`。

## 部署

Secrets（Settings → Secrets and variables → Actions）：

- `FEISHU_WEBHOOK`：必填
- `FEISHU_SECRET`：选填，机器人开启签名校验时需要
- `ANTHROPIC_API_KEY`：选填，用于生成 AI 点评

手动运行：Actions → A股每日推荐 → Run workflow，可以勾选"强制运行"或"只打印不推送"。

## 局限

- PE、PB 用的是行情快照的动态值，ROE 是推算值，不如财报精确
- 因子权重是按 A 股常见实证结论设定的先验值，需要用策略追踪的数据持续检验和调整
- 仅供研究参考，不构成投资建议
