# A股每日量化复盘 → 飞书

每个交易日北京时间 17:13 由 Claude 定时任务触发并检查是否发送成功，失败会重跑或修复（GitHub 自带定时延迟严重，只保留 21:37 兜底；当天只推一次），向飞书群推送复盘卡片。股票名可点击跳转雪球。

目标：选出**推荐后一段时间内涨幅可观**的股票。每晚用全市场真实数据评选策略，每天复盘实盘表现，表现差的策略自动替换。

## 卡片结构

1. **市场概况**：涨跌家数、成交额、沪深300 状态、领涨行业
2. **📝 昨日复盘**：上一交易日推荐的股票今天的表现，按策略拆分
3. **🔧 今日策略调整**：哪些策略上线、下线及原因；今天上场的策略各分到几个名额
4. **🎯 今日推荐**：最终推荐，标注来自哪个策略
5. **📌 推荐跟踪池**：最近 10 个交易日推荐过的股票，显示累计涨幅、连涨天数，以及是否跌破止损
6. **📈 策略实盘战绩**：每个策略推荐后 5 日的平均涨幅、上涨比例、涨超 5% 比例

## 评判标准

所有策略统一按**推荐后 5 个交易日的涨幅**评判：看 5 日平均涨幅、5 日上涨比例、涨超 5% 的比例。回测、实盘战绩和名额分配都用这一个口径。

## 策略库（`variants.py`，8 类 22 个参数版本）

| 类别 | 思路 | 版本 |
|---|---|---|
| 🔥 强势延续 | 均线多头、20 日稳步上涨、贴近新高、未过热 | 标准 / 激进 / 稳健 |
| ↩️ 趋势回踩 | 上升趋势中缩量回调到 20 日线后企稳 | 标准 / 深回踩 / 浅回踩 |
| 🚀 底部启动 | 长期下跌后在低位放量启动 | 标准 / 深跌 / 宽松 |
| 🛡️ 稳健多因子 | 行业内估值/ROE/低换手占优 + 60 日趋势平稳 | 标准 / 严格 |
| 💥 放量突破 | 横盘整理后放量突破 60 日新高 | 标准 / 强 |
| 🪃 超跌反弹 | 短期急跌、远离均线后放量反弹 | 标准 / 深 |
| 🐢 低波稳涨 | 低波动、60 日稳步上涨、回撤小 | 标准 / 宽 |
| ⚡ 涨停回踩 | 首板涨停后缩量回踩、不破涨停当天低点（涨停当天买不进，等回踩再介入） | 标准 / 紧 / 次日承接 / 两个小盘低价版（市值≤100亿、股价≤15元） |

所有指标都由 `features.py` 用同一套代码计算：滚动回归斜率和 R²、均线、量比、回撤、底部形态等。实盘取最后一天，回测取历史上的每一天，所以回测验证过的策略就是实盘在跑的策略。

## 涨停复盘（`limitup.py`）

每日推荐之后在同一个工作流里运行，单独发一张「⚡ 涨停复盘」飞书卡片：情绪温度（涨停/炸板/跌停、炸板率、昨日涨停溢价、晋级率、最高板）、周期判断、涨停主线、连板梯队、代表股的主力手法推测（封板时间、炸板次数、换手率、龙虎榜席位：机构/北向/营业部/拉萨散户席位）、当日心得（有 `ANTHROPIC_API_KEY` 时 AI 撰写，否则规则生成）、涨停系策略的回测结果。东方财富涨停池不可用时用行情快照 + 历史缓存自算。每日指标存 `data/limitup.csv`，用于和前几天对比判断情绪周期。

## 自我学习：上场策略评选与替换（`roster.py`）

**每晚评选**：夜间回测给 22 个版本逐一打分，选出 4 个第二天上场。入选必须同时满足：
- 回测 120 天里至少 30 天有信号，累计至少 100 只推荐
- t 值 ≥ 1。t 值用不重叠的 5 日窗口计算，避免样本自相关夸大显著性
- 前 60 天、后 60 天的 5 日平均涨幅都跑赢随机选股，防止只在某段行情里碰巧有效
- 不在冷却期

满足条件的按综合分排序：回测均值先按 n/(n+100) 收缩，样本少的打折；实盘数据越多，实盘表现的权重越大。同一类最多上场 2 个版本。

**实盘熔断**：每天推荐前检查上场策略最近 10 只已满 5 日的推荐。平均 5 日涨幅低于 −3% 的立即下线，冷却 10 个交易日，由排名靠后但合格的版本补位。

每次上线、下线和原因都会写在卡片的"今日策略调整"里，并记录到 `data/roster_log.csv`。

## 名额分配（`alloc.py`）

每天 10 个名额，在上场的 4 个策略之间按贝叶斯方法分配：
1. 先验：夜间回测的 5 日平均涨幅，打五折，相当于 4 个实盘样本
2. 实盘证据：满 5 日的推荐按 5 日涨幅计；未满 5 日的按 3 日或次日涨幅折算，权重降低
3. 时间衰减：半衰期 7 个交易日
4. 蒙特卡洛模拟每个策略"是最好策略"的概率，按概率分配名额

其他规则：最近 3 个交易日推荐过的股票不重复推荐，在跟踪池里继续看；同一行业最多 3 只；止损参考价最多低于现价 10%。

## 部署

Secrets：`FEISHU_WEBHOOK`（必填）、`FEISHU_SECRET`、`ANTHROPIC_API_KEY`（选填）。
手动运行：Actions → A股每日推荐 → Run workflow（可选强制运行 / 只打印不推送 / 行情源）。

## 局限

- 数据来自免费接口（东方财富 / 腾讯 / 新浪），海外服务器常被东方财富限流，会自动切换备用源
- 推荐和回测都按收盘价计算，实际买入一般在次日开盘
- 策略权重和阈值是先验设定，名额分配需要积累几周数据才会稳定
- 仅供研究参考，不构成投资建议

## 夜间回测（`backtest.py`）

用全市场真实历史行情回放过去 120 个交易日。每一天只用当时能看到的数据，让 22 个策略版本各选前 10 只，记录之后 1/5/10 天的真实涨幅。
对照组：🎲 随机基准，每天随机选 10 只；📈 追涨基准，每天买涨幅 5~9% 的成交额前 10 只。

报告推送到飞书，内容包括：
- 明日上场名单及变动原因
- 每个版本的 5 日平均涨幅（与随机对比）、t 值、5 日上涨比例、涨超 5% 比例、10 日平均、前后半段表现

股票池为全市场，剔除 ST、北交所、当前市值 < 50 亿，回放的每一天再按当天成交额 ≥ 1 亿过滤，和实盘规则一致。
近似：按当前上市状态和市值筛选，有幸存者偏差；稳健多因子用的是当前 PE/PB，有前视偏差。

## 全市场历史行情缓存（`histstore.py`）

每日选股和夜间回测都扫描全市场，不设候选数量上限。逐只拉取全市场历史数据约需 5000 次请求，所以做了缓存：

- 首次全量拉取约 400 个交易日的前复权日线，存到 `cache/hist.pkl.gz`，通过 GitHub Actions cache 跨次运行保留，不进 git
- 之后每天用全市场快照（约 20 次请求）给每只股票追加当天 K 线
- 快照的"昨收"和缓存最后一天的收盘价对不上时（除权除息、中间缺数据），这只股票会自动重新完整拉取
- 拉取有时间预算，没拉完的下次继续补；手动运行"策略夜间回测"并选 mode=build，可以只构建缓存
- 成交量统一用"手"

## 每日观点报告（纯文字）

每个交易日收盘后：

1. 每日推送任务的最后一步 `market.py` 生成盘面数据摘要 `data/market/日期.txt`，内容包括：
   - 指数和关键价位
   - 量能
   - 涨跌结构及近 10 日变化
   - 大中小盘风格
   - 行业
   - 成交额前 15
   - 量价异动形式的主力行为线索：高位放量冲高回落、高位放量下跌、趋势中缩量回调、底部放量异动、放量突破新高
   - 涨停情绪和龙虎榜（来自 `limitup.py`）
   - 量化系统的回测结论
2. Claude 定时任务根据摘要和当天新闻撰写观点报告，提交到 `data/reports/日期.md`。报告包括：
   - 回顾昨日判断的对错
   - 今日盘面
   - 主力动向与操盘手法解读
   - 未来 1–5 个交易日的情景和关键点位
   - 应对思路
3. 报告一提交，`report.yml` 就把它以纯文字推送到飞书，超长时按段落拆成多条。

报告中的主力手法属于基于公开数据的推测，所有观点仅供研究参考，不构成投资建议。
